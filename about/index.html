ABOUT · MANIFESTO

做 Agent 的人，在这里相遇。

Agent Hub 汇聚正在塑造智能体未来的一线研究者、工程师与跨学科同行。

我们相信，通用智能体的演进不仅取决于模型规模与算力，更取决于谁在构建它、彼此如何协作，以及哪些真问题被持续追问。从基模训练、Agent Harness、自我改进（RSI）到 AI4Science、AI 安全与物理世界智能，真正推动前沿的，往往是一群愿意分享真实实验与卡点的人。

Agent Hub，就是让这些对话与共建发生的地方。

我们的信念

01

研究者与构建者优先。

社群的核心是高密度的同行连接。基模研究员、高校教授、青年硕博与自然科学学者平等交流，不唯头衔，只看真问题与真工作。

02

社群本身就是产品。

日报、周报、资料库和线下活动都是自然产出；真正沉淀下来的，是一张高信任的技术网络，让有价值的问题找到对的同行。

03

重实质，轻喧嚣。

我们更看重跑得通的系统、可复现的评测、没跑通的实验细节与长期研究杠杆，而不是短期流量。扎实的工作会复利，喧嚣终会退潮。

04

开放前沿，也直面责任。

当智能体越来越强大，评测、安全与可控部署不再是附注。我们欢迎诚实讨论能力边界与风险，推动稳健而负责任的前沿探索。

我们如何运转

天生为 Agent 而建。

日报、周报、资料库与术语档案同步提供 llms.txt、RSS 与 agenthub Skill——既给人读，也能直接接入你的 Agent 工作流。

精选，而非泛流量。

坚持审核与成员推荐制，优化信噪比、信任度与讨论深度，把大家的时间留给有实质反馈的技术交流。

平台，而非单一流水线。

支持论文拆解、Benchmark 复现、开源项目共建与跨学科对话；成员自主发起方向，社群提供密度与长期基础设施。

我们在构建什么

  • 面向全球一线 LLM Agent 研究者与工程师的开放技术共同体

  • 持续沉淀的社群日报、周报、资料库与群聊黑话档案

  • 连接 Benchmark 复现、开源共建与 AI4Science 跨学科探索的协作网络

  • 人与 Agent 共同阅读、共同演进的可持续 AI 原生基础设施
