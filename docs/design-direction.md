## 定位与内容

Agent Hub 连接研究者、工程师与对 Agent 保持好奇的人。定位围绕 Agent 研究与实践，不以语言或地域划定范围。文案强调论文、亲身实验、未解决的问题和人与人的交流。首页以研究交流为主：方法是否有效、评估是否可信、工程代价、实验复现，以及尚未解决的问题。

内容依据：

- [2026-11-05 日报总览](https://agent-hub-community.github.io/newspaper/daily/2026-11-05/overview/)：Agent 接口、异步 RL 稳定性与机器人的实际表现。
- [日报机器可读目录](https://agent-hub-community.github.io/newspaper/index.md)：日期、版面与永久链接。
- [2026-10-26 至 11-01 周报](https://agent-hub-community.github.io/newspaper/weekly/2026-10-26/2026-11-01/group-1/)：Personal Agent、形式化验证、RSI 与研究工具。
- 原有 `src/community-data.json`：66 则讨论摘录和全部成员机构资料，原样保留。

日报是带日期的人工精选，每篇链接原文。活动区描述希望开展的交流形式，不增加活动日期、人数或机构合作关系。成员所在机构与高校按原始资料呈现。加入方式仍为成员邀请，首页呈现现有 GitHub 入口；独立申请示例作为设计参考保留，不在首页加入区推广。

## 视觉系统

正文常规版心上限为 1200px；超过 1920px 的宽屏中，图文随视口平滑展开，至 2160px 时达到 1440px 版心上限。整页共享边距、文字层级和两级背景色。暖白与墨黑建立阅读对比，研究方向使用一块深蓝灰色区域建立明暗节奏。铜色只用于插图细节和交互强调。界面字体使用自托管 Inter 与 Noto Sans SC 字体子集，系统中文字体作为后备，品牌继续使用原字标。社群讨论中的一段摘录采用自托管 Noto Serif SC 字体子集（5.2 KB），保留来源与 OFL 许可。

1. 社群介绍：做 Agent 的人在这里相遇；从论文、实验和没跑通的问题说起，保留两个清晰入口。
2. 日报精选：一篇主文章、两篇并列次文章。原创 SVG 研究插图表达 Code / AX Tree / GUI、内核对齐与机器人实践，主图保留石墨色表面；日间的两张次图采用暖浅色展示面，夜间仍为深色。细描边和铜色强调形成层次。它们是示意图，不是实验截图或指标。悬停与键盘焦点有有限的连接线与对象反馈。
3. 研究方向：六项同时显示，851px 及以上使用两列目录，编号与标题共行，原始讨论中的具体问题接在下方。较窄屏幕保留先前的排法。点击直接展开对应讨论，不要求先操作标签才能了解内容。
4. 讨论摘录：问题下直接呈现一句原有摘录，展开后接着阅读完整上下文。保留全文搜索、筛选、分页与完整原始资料。支持 `#discussion-N` 直达链接，自动打开正确页和摘录，键盘焦点跟随；现代浏览器渐进增强展开动效。
5. 社群交流：一段关于形式化验证与人的理解的真实讨论摘录，链接到完整上下文；四种希望开展的交流、静态机构网格与可展开的完整机构目录。没有虚构成员身份、活动或证言。
6. 加入与页脚：明确成员邀请制，使用原有字标作为大幅落款，与开场呼应。页脚保留日报、资料库、RSS、GitHub 与回到顶部的清晰入口。

正文采用短暂的进入过渡、文章插图的有限反馈与原生折叠过渡，没有持续运行的正文动画。前一设计的资源备份在 `.hallmark/v2/`，不再随页面加载。
